思路：颜色分割出灯条掩膜 → 轮廓拟合成旋转矩形筛选灯条 → 两两配对判据找左右灯条 → 四点连成装甲板并绘制。


颜色分割：makeMask 用 HSV 阈值（红色需要合并两段区间）或 BGR 通道差做二值化，再经过开运算和闭运算，得到灯条掩膜。
灯条筛选：findLightBars 先对每个轮廓取 minAreaRect，再按面积、长宽比 ≥2.5、填充率 ≥0.4 这三项条件筛选；四角按 y 排序后，取上下边中点，算出灯条长度与方向角（归一到 0–180°，消除方向二义性）。
两两配对：isPair 用三项归一化判据，即方向角差 <15°、长度相对差 <0.4、中心 y 差 <0.5（后两项以灯条长度作为分母，因此与尺度无关）；matchLightBars 在所有合法组合中取两条长度中的较小值最大的一对，按 x 坐标区分左右。
装甲板绘制：四角按 左上→右上→右下→左下 连成绿色框，--debug 时叠加所有候选灯条。
